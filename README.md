## 🚀 What is flowy?

flowy is a visual workspace for GitHub repositories. It turns a codebase into an interactive mind map so you can see how the project fits together.

Use it to:
- explore a repo without reading every file first
- understand the main parts of a codebase
- follow links between folders, files, and modules
- keep your view in sync with Git changes

It is made for people who want a fast way to look through a repository on Windows.

## 🧠 What you can do in flowy

flowy helps you browse a repository in a visual way.

### 🔎 Explore code structure
See how folders and files connect. This makes it easier to understand large projects.

### 🌐 View the repository as a mind map
Each part of the codebase appears as a node. You can move around the map and focus on one area at a time.

### 🔁 Keep Git in sync
flowy works with Git updates, so your view stays close to the current state of the repository.

### 🧩 Follow relationships
Use the map to trace how one part of the project connects to another. This is useful when you want to find where something starts or where it is used.

### ⚙️ Work with modern web apps
flowy uses a modern desktop-style interface built for current GitHub workflows.

## 🖱️ How to use flowy

1. Start the app.
2. Choose a repository.
3. Let the app build the visual map.
4. Click a file or folder to inspect it.
5. Drag the map to move around.
6. Zoom in when you need more detail.
7. Zoom out when you want the big picture.

If the map feels crowded, focus on one folder first. That often makes the layout easier to read.

## 🧰 Troubleshooting

### The app does not open
- Make sure the download finished.
- If the file is zipped, extract it first.
- Try running the app again as the current user.

### The repository does not load
- Check your internet connection.
- Make sure the repository URL is correct.
- Sign in to GitHub if the repo needs access.

### The map looks empty
- Wait for the first sync to finish.
- Refresh the repository view.
- Try a different repository with more files.

### Git changes do not appear
- Confirm that the repository is linked to the right local or remote source.
- Pull the latest changes in Git if needed.
- Reload the project in flowy.
