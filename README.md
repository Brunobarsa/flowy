## 🚀 What is Flowy?

Understanding a new repository or navigating a complex architecture can take hours of scrolling through files. **Flowy** solves this by converting any GitHub repository into a beautiful, interactive mind map.

Simply paste a GitHub URL, and Flowy will analyze the architecture, generate a comprehensive visual map of the codebase, and keep it updated automatically whenever a new commit is pushed. It is the ultimate visual workspace for developers, tech leads, and open-source contributors.

## ✨ Key Features

- **🧠 Instant Mind Maps:** Paste a GitHub URL and get a complete visual hierarchy of the codebase in seconds.
- **👁️ Interactive Visual Workspace:** Navigate through nodes, explore folder structures, and understand the relationship between files without reading a single line of code.
- **🔄 Real-Time Git Sync:** Never look at an outdated architecture. Flowy syncs with your repository and updates the mind map automatically on every new commit.
- **⚡ Bleeding-Edge Performance:** Built to handle massive codebases smoothly using the latest experimental features of React 19 and Next.js 16.
- **🎨 Beautiful UI/UX:** Smooth animations and a premium interface powered by Tailwind CSS v4 and Framer Motion.
